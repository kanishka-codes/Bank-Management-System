## Simple Bank Management System 

A beginner-friendly Bank Management System built using **C++ structures**,  
**data hiding**, and **user-defined functions**.

This project helps users:

Create an account  

Deposit money  

Withdraw money  

Check balance  

Change their PIN  

All banking data is kept private using structure-level encapsulation.

---

##  Features

### Create Account
- Enter name  
- Set a secure 4-digit PIN  
- Add initial deposit  

###  Deposit Amount
- PIN verification  
- Updates balance securely  

###  Withdraw Amount
- Checks sufficient balance  
- Secure PIN entry  

###  Check Balance
- Protected by PIN  
- Shows current balance  

###  Change PIN
 Old PIN verification  
 New 4-digit PIN validation
